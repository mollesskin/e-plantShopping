# e-plantShopping

## Paradise Nursery Shopping Application

A React shopping application for browsing and purchasing houseplants.

The application includes:
- A landing page introducing Paradise Nursery.
- A product catalog organized into plant categories.
- A shopping cart with quantity controls, item removal, and total cost calculation.
- Redux Toolkit for shopping cart state management.

Built with React, JavaScript, CSS, and Redux Toolkit.
